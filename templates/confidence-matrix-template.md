# Confidence Matrix Template

Copy this table and fill one row per claim. Keep inferences and hypotheses out of the
"fact" column.

| 1 |  |  | FACT / OBSERVATION / INFERENCE / HYPOTHESIS / UNKNOWN | Confirmed / High / Moderate / Low / Unknown |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |

## Rules

- **FACT** — directly supported by captured evidence.
- **OBSERVATION** — seen but requires interpretation.
- **INFERENCE** — reasoned from multiple observations; never printed as fact.
- **HYPOTHESIS** — plausible, unproven; always labeled.
- **UNKNOWN** — insufficient evidence → write *"Evidence does not support a definitive
  conclusion."*

## Confidence anchors

- **Confirmed** — established directly by evidence.
- **High** — strongly supported; alternatives unlikely.
- **Moderate** — supported, but meaningful alternatives exist.
- **Low** — weakly supported; speculative.
- **Unknown** — cannot be assessed.
